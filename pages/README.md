## Установка

### 1. Скопируйте страницы

Скопируйте все папки (`01.home`, `02.main`, и т.д.) в:
```
user/pages/
```

### 2. Настройте конфигурацию

Скопируйте `site.yaml` в:
```
user/config/site.yaml
```

### 3. Подключите стили

Вариант A — **Custom CSS плагин:**
1. Установите плагин Custom CSS
2. Вставьте содержимое `modern-styles.css` в админке

Вариант B — **Кастомная тема:**
1. Скопируйте `modern-styles.css` в:
   ```
   user/themes/[ваша-тема]/css/custom.css
   ```
2. Подключите в шаблоне темы:
   ```twig
   {{ assets.addCss('theme://css/custom.css') }}
   ```

### 4. Добавьте изображения

Скопируйте файлы изображений (`.png`) в папку `03.daily/`:
- `daily_res.png`
- `1пн.png` — `7вс.png`

Или поместите их в:
```
user/pages/03.daily/
```

## Особенности Grav-разметки

### Информационные блоки

Используются нотификации Grav:

```markdown
! Обычная информация (синий)
!! Важное предупреждение (жёлтый)
!!! Критичное предупреждение (красный)
```

### Таблицы

Стандартный Markdown:

```markdown
| Заголовок 1 | Заголовок 2 |
|-------------|-------------|
| Ячейка 1    | Ячейка 2    |
```

### Ссылки

Внутренние ссылки используют слаг:
```markdown
[Текст ссылки](/heroes)
```
