# Глоссарий терминов

## Сокращения и термины

### Здания

| Термин | Полное имя | Функция |
|--------|------------|---------|
| **ЭС, Электричка** | Электростанция | Главное здание, открывает всё |
| **СС** | Станция связи | Требование для электростанции |
| **Лаба** | Лаборатория | Науки и проценты |
| **Каз** | Казарма | Обучение войск |
| **Госпиталь** | Госпиталь | Лечение раненых |
| **Академия** | Академия героев | Книги талантов героев |
| **Мастерская** | Мастерская артефактов | Ускорение строительства |

### Игровые механики

| Термин | Определение |
|--------|-------------|
| **Марш** | Отправка войск на плитку/боевую операцию |
| **Ячейка марша** | Одновременно активный марш (макс 5) |
| **Плитка** | Ресурсная клетка на карте (уровни 1-7) |
| **Сбор** | Получение ресурсов с плитки |
| **Фарм** | Систематический сбор ресурсов |
| **Наука** | Исследование в лаборатории (дает проценты) |
| **Боевая мощь** | Общий показатель силы (все бонусы + уровни) |
| **Синергия** | Бонус за 3 предмета одного цвета |
| **Кэшбэк** | Возврат части потраченного (ускорений) |

### События

| Сокращение | Полное имя | Описание |
|------------|------------|----------|
| **Игра** | Игра по-крупному | Ежедневное событие (6 фаз) |
| **Черепашка** | Турбо-черепашка | Еженедельный рейтинг сбора (вс-сб) |
| **Дуэль** | Дуэль союзов | Еженедельное событие (7 дней) |

## Специальные термины

### "Копить" vs "Тратить"

**Копить:**

- Собирать ресурсы без траты
- Копить на VIP, события, ускорители

**Тратить:**

- Использовать ресурсы немедленно
- Обычно неправильно для новичков

### "Выкладываться"

Означает максимальное участие в событии (собрать максимум ресурсов, прокачать максимум героев и т.д.).

### "Быть в тренде"

Означает идти в ногу с другими игроками (не отставать).

### "Гореть" / "Выгореть"

Потерять интерес к игре из-за перегрузки или скучности.
